# Security policy

Project Flow is a set of agent instructions. It can encourage safer work, but it cannot guarantee that an application or repository is secure.

## Reporting a problem in this repository

Do not post credentials, private data, or working exploit details in a public issue. If GitHub private vulnerability reporting is enabled for this repository, use it. Otherwise contact the repository owner through the GitHub profile and share only the minimum details needed to arrange a private report.

## Scope of security work guided by this skill

Security testing must stay within systems the user owns or is authorized to assess. Confirm target and scope before active testing. When authorization is unclear, provide a safe review or test plan and wait. Never treat public access to a website as permission to test it.
